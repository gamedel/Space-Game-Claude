# Space-Game-Claude

Скрипт для нарезки 2D-атласа на отдельные спрайты: `slice_atlas.py`.

## Быстрый запуск

```bash
python slice_atlas.py --input atlas.png --output-dir sprites
```

После запуска скрипт:
- экспортирует каждый найденный спрайт в `sprites/sprite_XXX.png`;
- создаст `sprites/sprites.json` с координатами вырезанных областей.

## Параметры

- `--alpha-threshold` — порог альфа-канала (по умолчанию `10`);
- `--rgb-threshold` — порог «чёрного фона» по RGB (по умолчанию `24`);
- `--min-area` — минимальная площадь компонента в пикселях (по умолчанию `64`);
- `--padding` — прозрачный отступ вокруг спрайта (по умолчанию `2`).
